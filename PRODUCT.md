## Product Purpose

Omega Systems tracks production equipment, assignments, returns and maintenance. The existing implementation and README establish these capabilities; this record does not add commercial claims.

## Users

- Administrators manage equipment.
- Individual crew accounts view inventory and operate their own assignments.
- The owner requested a public `user` sign-in on the login page so visitors can look around. That reserved account is read-only.

## Capabilities and Constraints

React and TypeScript with Tailwind; a standalone PHP/MySQL API on Hostinger. Credentials and permissions are checked by PHP. The public visitor must not change inventory or incur AI-provider requests. Preserve the existing product and navigation while extending the sign-in form.
